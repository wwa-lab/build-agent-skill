# Atlas Build Tool Mini Output Sample

This sample is a sanitized, fictional M4 Build package. It shows the type of evidence bundle the repo can help produce when upstream discovery/design material is ready enough for controlled implementation work.

The example uses generic IBM i names:

- Program: `CUSTMNT`
- Physical file: `CUSTMAST`
- Test library: `ATLASTEST`
- Business rule: `BR-01`

## Files

| File | Purpose |
|------|---------|
| [01-mini-requirement.md](01-mini-requirement.md) | Safe input representing upstream discovery/design evidence. |
| [02-task-md-plan-sample.md](02-task-md-plan-sample.md) | Representative approved `task.md` batch plan excerpt. |
| [03-program-spec-excerpt.md](03-program-spec-excerpt.md) | Program Spec excerpt with traceability. |
| [04-generated-rpgle-excerpt.md](04-generated-rpgle-excerpt.md) | Generated RPGLE excerpt from the Program Spec. |
| [05-ut-plan-excerpt.md](05-ut-plan-excerpt.md) | Unit Test Plan excerpt. |
| [06-test-scaffold-excerpt.md](06-test-scaffold-excerpt.md) | SQL/CL test scaffold excerpt for M5 handoff. |

## Notes

- This is not a full production artifact.
- It intentionally uses small excerpts so reviewers can scan the M4 Build story quickly.
- All names and data are fictional.
- Generated code and DDS should always pass human IBM i review before compile or deployment.
